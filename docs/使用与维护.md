# 小爱触屏音箱 LX04：DeepSeek 接入

程序、账号配置和开机启动均位于音箱。日常使用只需音箱接电、连 Wi-Fi；Mac 和 NAS 不需要运行服务。大模型推理调用 DeepSeek 云端 API，并非在这台约 1 GB 内存的音箱上运行完整模型。

## 怎么说

仍用“小爱同学”唤醒，直接说问题，不需要“请问”等前缀。

| 内容 | 处理方式 |
| --- | --- |
| 天气、空气质量、时间 | 原生小爱 |
| 明天穿什么、今天带不带伞、周末晒被子等天气相关建议 | 原生小爱，利用本地天气预报 |
| 家居控制、播放音乐、调音量、闹钟和计时 | 原生小爱 |
| 知识解释、一般问答、写作、翻译 | DeepSeek |
| 最新动态、排名、新闻，或明确要求联网搜索的问题 | 音箱调用 DeepSeek 官方搜索接口后，再由模型回答 |

分流目前使用本机规则：明确的原生功能优先，其余开放问题交给 DeepSeek。它不是一个能准确理解所有新说法的通用意图模型；发现误分流时，可记录原话并补充规则。历史知识问题如“唐朝人穿什么衣服”仍交给 DeepSeek。

## 实现与验证

- 使用原厂 Android 8.1 的本机 ASR 日志，直接接收最终识别文本；不再轮询小米云端对话记录。
- 在判断走 DeepSeek 后暂时抑制原生播报，原生收到 DeepSeek 回答的 Speak 指令时恢复声音；超时、请求失败、进程正常退出也恢复。音量值保持原样。
- 保留原厂桌面、小米绑定、唤醒与原生功能。启动时的已解锁提示来自当前调试启动镜像。
- 用户已确认自动分流版本知识问答与原生天气正常。穿衣规则已补充，重启自启动和最终回归结果见《实机操作记录》。
- 用户已确认更新后穿衣建议、知识问答及其他测试均正常。
- 联网搜索版本也已获得用户实际语音验收，反馈“都正常，比较满意”。
- 音箱直接调用 DeepSeek API 已通过；实际知识问答生成约 1–1.5 秒，完整播报启动还包括原生 TTS 的网络时间。

联网搜索复用同一个 DeepSeek API Key，不需要额外搜索服务或 NAS。明确的时效问题会先搜索；其他问题也允许模型自行调用 `web_search`。每次提问最多两次搜索，普通稳定知识不强制搜索。模型榜单优先检索评测机构原站，区分能力、人气和市场份额。搜索失败或没有资料时明确说无法核实，不把旧知识冒充最新搜索结果。

搜索来源和查询时间保存在音箱私密目录的 `last-search.json`，包含网页标题与链接，方便事后核对。网页内容只作为资料，不授予执行命令或操作家居设备的能力。

按 2026-10-24 的[DeepSeek 官方文档](https://api-docs.deepseek.com/guides/search/)，独立 Search API 按成功请求计费，每 1,000 次 0.75 美元，另加模型调用费用；一次提问最多两次搜索。不要将官方针对部分代理产品的阶段性免费说明理解成永久免费。

## 文件位置

音箱上的私密目录为 `/data/adb/lx04-deepseek`，权限 0700：

- `lx04-agent`：ARMv7 独立程序。
- `config.json`：DeepSeek Key、小米账号与配置，权限 0600。
- `.mi.token`：小米登录令牌，权限 0600。
- `run.sh`：启动与退出音频恢复脚本。
- `runtime.log`、`runtime.previous.log`：本次与上次启动日志，包含 DeepSeek 提问及回答；原生请求只记录分流结果。
- `last-search.json`：最近一次联网搜索的原问题、时间、网页标题、链接和摘录，权限 0600。
- `.audio-restore.json`：仅临时接管声音时存在，保存接管前的播放静音状态，恢复后删除。

Magisk 开机入口：`/data/adb/service.d/lx04-deepseek.sh`。

本机 `.secrets/` 保存私密配置副本，不提交到 Git。原厂完整备份在 `backups/`；候选镜像、程序和构建散列在 `artifacts/`；公开客户端完整源码在 `client/`，变更补丁保存在 `docs/xiaobot-local.patch`。

## 暂停与恢复 DeepSeek

下列命令在 Mac 的项目目录执行，假定已将官方 Platform-Tools 的 adb 加入 PATH。USB 调试使用独立端口 5038；O+Connect 的后台 ADB 可能抢占接口，调试期间须保持它关闭。

暂停：

```sh
adb -P 5038 shell touch /data/adb/lx04-deepseek/disabled
adb -P 5038 reboot
```

恢复：

```sh
adb -P 5038 shell rm -f /data/adb/lx04-deepseek/disabled
adb -P 5038 reboot
```

若意外中断后没有声音，可用程序的恢复入口读取已保存的原状态：

```sh
adb -P 5038 shell /data/adb/lx04-deepseek/lx04-agent -restore-audio
```

以上只暂停或恢复附加程序。完整恢复原厂启动镜像与启动锁使用另行准备的备份恢复方案，不能仅凭此文覆盖其他机型镜像。

## 网络与账号维护

原机验收版使用本网络已验证的路由器 DNS，原厂系统 DNS 不改。公开启动模板优先读取私密 `dns-server.txt`（IP:端口），随后尝试 Android DNS 属性和默认网关；建议按自己的网络明确配置。更换网段时，已安装旧版仍需调整旧 `run.sh` 中的 DNS 与路由等待地址；公开整理没有自动更新原机。

当前模型为 `deepseek-flash`，关闭思考模式，回答控制为适合语音朗读的短中文。调用会使用账号的 API 配额或余额。账号令牌失效时，原生小爱继续工作；附加程序需要重新完成小米登录验证。密码、验证码及 API Key 都应通过私密文件配置。
